# Retinal Blood Vessel Segmentation

## Project Overview
This project explores retinal blood vessel segmentation using a hybrid deep learning model that combines Transformer U-Net and Graph Neural Networks (GNN).

## Datasets
- DRIVE
- STARE

## Technologies
- Python
- PyTorch
- Deep Learning
- Transformers
- Graph Neural Networks
- Jupyter Notebook

## Project Files
- `DRIVE_HybridTransUNet_GNN_V4.ipynb` — DRIVE dataset experiment
- `STARE_HybridTransUNet_GNN_V4.ipynb` — STARE dataset experiment

## Project Goal
The goal is to identify blood vessels in retinal images while preserving small vessels and vessel connections.
